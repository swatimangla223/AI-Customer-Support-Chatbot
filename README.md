# AI Customer Support Chatbot

A simple Streamlit-based chatbot for answering common customer support questions such as refunds, shipping, order status, billing, and account issues.

## Features
- Chat-style support interface
- Quick help examples
- Rule-based responses for common support topics

## Requirements
- Python 3.10+
- Streamlit

## Run the app
From the project folder, run:

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

Or use the virtual environment Python directly:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## Project files
- app.py - Main Streamlit application
- requirements.txt - Python dependencies
